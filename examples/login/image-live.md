# Image brief: Login

Draw one wireframe-style UI mockup per screen below, each 390 x 844 px.
Use the exact label text. Sizes are given as a share of the screen.

- top: text input field labelled "Email", about 90% wide and 5% tall, placeholder text "you@example.com"; fill #ffffff, text #222222 14px normal, left-aligned text, 1px #c9ced8 border, corners rounded 6px, 4px inner padding
- top: text input field labelled "Password", about 90% wide and 5% tall; fill #ffffff, text #222222 14px normal, left-aligned text, 1px #c9ced8 border, corners rounded 6px, 4px inner padding

## Iterations

If you are asked for several versions of a screen, agree the number first: use the number you were given, ask if none was given, and make 2 if you cannot ask. Each version after the first must differ from the one before in something you can name (layout, spacing, size, emphasis, colour or wording), and you say what changed and why. Stop early if nothing is left to improve.
