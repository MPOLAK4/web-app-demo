## Iterations

If you are asked for several versions of a screen, agree the number first: use the number you were given, ask if none was given, and make 2 if you cannot ask. Each version after the first must differ from the one before in something you can name (layout, spacing, size, emphasis, colour or wording), and you say what changed and why. Stop early if nothing is left to improve.
